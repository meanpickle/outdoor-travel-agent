# 野途 · Outdoor Travel Agent

一个面向户外探索、独行旅行和携宠出行的中文旅行助手交互 Demo，展示「出发前规划 → 途中陪伴 → 旅行归档」的完整流程。

**在线体验：[野途旅行 Agent](https://wildpath-travel-demo-0911.pczhou561.chatgpt.site)**

> 当前版本使用前端规则引擎和模拟数据，不调用大模型或真实旅行服务，适合产品展示、比赛演示和后续开发。

## 功能

| 模块 | 当前能力 |
| --- | --- |
| 一句话规划 | 提取部分目的地、出发地、天数、预算与携宠信息，选择徒步经验后生成示例行程 |
| 行程工作台 | 按天查看路线、规划思路与预算估算，支持 1–10 天 |
| 物资清单 | 勾选、添加和删除物品，按携宠配置生成基础用品 |
| 途中陪伴 | 模拟暴雨并确认改线；疲劳反馈可缩短当前日程 |
| 沿途服务 | 展示补给、停车、医疗服务示例，位置与营业状态待核实 |
| 旅行账本 | 记录人民币消费，删除记录，计算实际支出与剩余预算 |
| 打卡与档案 | 保存文字笔记，根据记录组合旅行手记，导出 Markdown |

## 本地运行

准备现代 Node.js（例如 22 或更新版本）及现代浏览器。项目没有第三方运行依赖，无需安装 npm 包。

```bash
git clone https://github.com/meanpickle/outdoor-travel-agent.git
cd outdoor-travel-agent
node server.cjs
```

打开 **http://127.0.0.1:4173**。终端按 `Ctrl+C` 停止服务。本地服务器仅监听本机回环地址；在线部署可直接托管 `dist/` 静态目录。

## 推荐演示流程

1. 输入「周末从杭州出发，去莫干山两天，一个人带狗徒步，预算1500元」。
2. 点击「生成行程」，选择「入门」，查看行程和估算费用。
3. 打开「物资清单」，勾选装备并添加自定义物品。
4. 返回规划页面确认方案，进入「途中陪伴」。
5. 点击「模拟暴雨」，确认雨天方案，查看路线和预算同步调整。
6. 添加旅行笔记，到「旅行账本」记录一笔实际支出。
7. 结束旅行，查看并导出旅行档案。

也可以使用「模拟疲劳反馈」演示缩短行程，或通过快捷示例切换旅行需求。

## 项目结构

```text
outdoor-travel-agent/
├── dist/
│   ├── index.html   # 页面结构与入口
│   ├── style.css    # 桌面和移动端样式
│   ├── app.js       # 规则解析、行程状态、账本和导出逻辑
│   └── travel.jpg   # 户外氛围图
├── server.cjs       # 零依赖本地 HTTP 服务
└── README.md
```

技术栈：原生 HTML / CSS / JavaScript、Node.js 内置 HTTP 模块、浏览器 localStorage。

## 数据保存与隐私

- 数据存储在当前浏览器、当前站点的 `localStorage`，键名为 `wildpath-v1`，不上传云端。
- 不同设备、浏览器及站点地址之间不会自动同步。
- 新行程会替换当前记录；已有笔记或支出时会提示确认，需要保留时先导出档案。
- 规划估算与实际消费分开计算；账本仅支持人民币单人记账，不执行支付。
- 导出文件可离线阅读，但应用未实现离线地图或完整离线缓存。

## 当前限制

- 自然语言采用有限规则解析，无法理解任意需求；未识别信息使用默认值，路线为模板示意。
- 未接入大模型、实时天气、地图、交通、酒店、景点开放情况或携宠政策接口。
- 不会实际预订、支付、联系他人、定位报警或派遣救援。
- 尚未实现多人 AA、多币种汇率、找搭子、照片视频上传、视觉识别、通知提醒与云端同步。
- WebMCP 摘要读取仅在支持的浏览器中注册，兼容性尚未实测；普通交互不依赖它。

## 检查方式

```bash
node --check dist/app.js
node --check server.cjs
```

已完成语法检查及需求解析、账本求和、暴雨/疲劳路线和五个视图渲染的本地逻辑检查；未进行完整浏览器端自动化测试。

## 后续开发方向

接入大模型结构化规划、地图与天气 API、后端行程存储和登录，再扩展真实服务核验、多模态档案和多人记账。真实预订、支付需设计明确的用户确认流程。
